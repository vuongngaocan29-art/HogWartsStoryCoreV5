## LỆNH ĐỔI MÀU NAMEPLATE

Chạy lần lượt trong game:

```text
/npc select 3
/npc color &b

/npc select 4
/npc color &5

/npc select 5
/npc color &6

/npc select 6
/npc color &e

/npc select 7
/npc color &4

/npc select 8

/npc select 9
/npc color &8

/npc select 10
/npc color &6

/npc select 11
/npc color &9

/npc select 12
/npc color &2

/npc select 13
/npc color &6
```

Citizens dùng `/npc color &[mã]` để đổi màu nameplate của NPC đã chọn.

## TÊN HIỂN THỊ ĐỀ XUẤT

Nếu muốn đổi tên đầy đủ, chọn NPC rồi dùng `/npc rename [tên]`.
Ví dụ:

```text
/npc select 3
/npc rename Giáo_sư_Flitwick
/npc color &b
```

Package BetonQuest đã có tên hội thoại có màu riêng, nên phần hội thoại vẫn đẹp dù bạn giữ tên Citizens hiện tại.
